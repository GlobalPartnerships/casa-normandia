## 📜 Política Canónica: Dónde SÍ y Dónde NUNCA usar "Rooted Spaces"

| ❌ DÓNDE NUNCA SE USA | ✅ DÓNDE EXCLUSIVAMENTE SE USA |
| :--- | :--- |
| **Navbars / Headers Web:** Prohibido apretar *"by Rooted Spaces"* en la barra superior. La web debe decir: **Casa Normandía** \| *Hospitalidad Urbana*. | **Nota Conceptual de Pie de Página:**<br>«🌿 *Iniciativa de restauración ecológica y bienestar Rooted Spaces.*<br>© 2026 Casa Normandía. Operado bajo principios de GPMF.» |
| **OTAs (Airbnb / Booking / VRBO):** En portales se publica 100% como **Casa Normandía**. | **Dossier Familiar y Gobernanza:** Para explicar la visión de futuro a los propietarios. |
| **Volantes y Folletos Rápidos:** Se usa el logotipo directo sin paraguas. | **Bioproductos de Nilo:** Vinagres vivos, quesos de finca y tinturas botánicas (*«Cosechado bajo principios Rooted Spaces»*). |
| **Redes Sociales:** Prohibido abrir LinkedIn/Instagram vacíos de Rooted Spaces. | **Sellos Futuros:** Cuando la finca opere cabañas continuas de hospedaje. |
